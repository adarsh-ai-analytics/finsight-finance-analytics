## 🔍 Key Insights Found
- 🔴 Total Amount fell ₹539.14K YoY
- 🔴 10.9% Failed transactions — above benchmark
- 🟡 Loan EMI = Top product (₹12.31M, 9,140 txns)
- 🟡 Male customers = 53.3% of tax vs 46.7% Female
- 🟢 Maharashtra leads states at ₹2.1K tax
- 🟢 Premium = highest tax per customer (₹3.13)
- 🟢 Success rate = 85.2% of all transactions
